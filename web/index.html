Requisitions

New requisition

A job that is not sales is not scored by the sales criteria. Each CV file is matched against these skills by the CV service, and what comes back is a percentage with the CV's own evidence beside it, for a person to read — never a tier, never a rejection.

Candidates

Every field says where it came from and whether anyone checked it. A field nobody recorded is "not recorded", never a guess.

Type one in

A recruiter's own find. It arrives unchecked and waits in the review queue until a person checks it — and it is the way to try the pipeline, since candidates migrated from the sheet get no applications until OPN-11 is ruled.

Pipeline

Only the moves the step list allows. Every move is kept with who did it and when, and nothing can change it afterwards.

Review queue

Everything waiting for a person, with the reason it is there. The platform never rejects anyone by itself.

Reports
